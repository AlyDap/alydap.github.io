## 📂 Struktur Repositori
Repositori ini berfungsi sebagai "Etalase" publik. Isinya meliputi:
* `index.html` - Halaman utama portfolio.
* `aboutme.html` - Halaman profil detail (responsif untuk tampilan mobile).
* `img/` - Aset gambar projek dan profil.

> **Catatan:** Untuk menjaga keamanan kode sumber (Source Code) dari projek-projek tertentu, repositori aslinya disimpan secara **Private** dan dihosting menggunakan **Vercel**.
